# Support

Ultra Vision is an experimental open-source project maintained in public.

- **Setup, usage, or contribution question:** GitHub Discussions is not currently
  enabled. Use the
  [question form](https://github.com/kaantaskentt/ultra-vision/issues/new?template=question.yml)
  for local setup, testing, architecture, usage, or help choosing a bounded first
  contribution.
- **Reproducible bug:** use the bug-report issue form and include browser, operating system, camera state, steps, and console output with private data removed.
- **Feature proposal:** use the feature-request form and explain the user outcome before suggesting implementation.
- **Security vulnerability:** follow [SECURITY.md](./SECURITY.md) and use private vulnerability reporting. Never publish an unpatched security issue.

Public issues are not a private support channel. Do not upload private camera
recordings or frames, copyrighted music, secrets, browser profiles, or personally
identifying logs. Reduce examples to generated or redacted evidence before
submitting them.
