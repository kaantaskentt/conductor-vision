# Support

Ultra Vision is an experimental open-source project maintained in public.

- **Setup or usage question:** start a GitHub Discussion once Discussions are enabled, or open an issue if the documentation is missing something concrete.
- **Reproducible bug:** use the bug-report issue form and include browser, operating system, camera state, steps, and console output with private data removed.
- **Feature proposal:** use the feature-request form and explain the user outcome before suggesting implementation.
- **Security vulnerability:** follow [SECURITY.md](./SECURITY.md) and use private vulnerability reporting. Never publish an unpatched security issue.

Please do not upload private camera recordings, copyrighted music, secrets, or personally identifying logs.
